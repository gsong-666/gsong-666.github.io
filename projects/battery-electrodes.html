01 / Generative AI · Current research

Generative AI for Battery Electrodes

Generating realistic three-dimensional electrode microstructures from two-dimensional reference images, with validation centered on physical and transport-relevant fidelity.

  • Generative AI
  • Microstructure
  • Transport Simulation
  • Physical Validation
2D → 3D

Challenge

3D microstructure data are expensive to acquire.

High-resolution three-dimensional characterization is costly and scarce, which limits data-driven microstructure analysis and downstream property prediction.

Research direction

Use 2D evidence to construct useful 3D structures.

The framework synthesizes 3D battery-electrode microstructures from 2D references and evaluates whether the generated structures preserve physically meaningful morphology.

Method / 01

From reference image to simulation-ready structure

  1. 01

    Reference characterization

    Extract structural evidence from experimentally acquired 2D electrode images.

  2. 02

    3D generation

    Use a generative model to construct volumetric microstructures consistent with the reference morphology.

  3. 03

    Physical validation

    Evaluate generated volumes using statistical and topology-aware descriptors instead of visual similarity alone.

  4. 04

    Property workflow

    Use validated structures to expand scarce datasets for transport simulation and effective-property prediction.

Validation / 02

Transport-relevant fidelity

Generated structures are evaluated against descriptors that reflect both morphology and connectivity.

S2Two-point correlation
φPhase fraction
SSASpecific surface area

Research value

The goal is not merely photorealistic generation. The generated structures must be credible inputs for physics-based transport studies and scalable dataset augmentation.
